05 / 07

The Loop, in
Pseudocode.

# The Luhn checksum, run on every card field def is_valid_card(digits): total = 0 for i, d in enumerate(reversed(digits)): if i % 2 == 1: d = d * 2 if d > 9: d -= 9 total += d return total % 10 == 0

This check never touches a bank. It runs entirely in your browser, the instant you finish typing, before any network request exists.

Caption
Every credit card number you've ever typed has one digit whose entire job is catching your typos, before the number ever reaches a bank. Accepting a card number with no validation at all means a single fat-fingered digit sails straight through to the payment network, wasting a full round trip only to bounce back as declined. Checking just the digit count catches almost nothing either, plenty of sixteen-digit strings look plausible and correspond to no card ever issued. Real validation needs to check whether the number itself is mathematically consistent, not just correctly shaped. That's what the Luhn algorithm does, and it's been quietly running under every major card network since 1954, long before the internet existed to validate anything over. Starting from the rightmost digit and moving left, every second digit gets doubled. Any doubled value over nine has nine subtracted from it, a shortcut equivalent to summing its two digits. Every digit, doubled or untouched, gets added into one running total. A genuine card number is constructed so that total always lands on an exact multiple of ten. This check never touches a server. It runs entirely in your browser or your phone's keyboard, the instant you finish typing, and catches roughly nine out of ten single-digit typos on the spot, with zero network latency and zero cost. Visa, Mastercard, and American Express numbers are all built to satisfy this exact same formula, despite being issued by completely different networks with no shared infrastructure. The same trick shows up far outside payments. IMEI numbers identifying phones, and several national ID formats, use the identical checksum principle for the same reason, catching a transcription slip before it causes a real problem downstream. That final digit was never encoding anything about your account. It exists purely so a simple formula can catch a mistake before a human, or a bank, ever has to. #luhnalgorithm #fintech #checksum #paymentsystems #ravenextechnologies
