Caption
A classic robot control stack was a chain of separate systems. One module looked at the camera and attached labels to objects, a planner chose a sequence of steps from a fixed menu, and a controller ran motions that had been programmed in advance. It worked, but it could not improvise. If the vision module had no label for an object, that object effectively did not exist to the robot, and if an instruction was phrased outside the planned command set, nothing happened. Vision-language-action models collapse that chain into a single network. The model takes in the raw camera image and a natural-language instruction and outputs the robot's action directly, as a sequence of tokens, the same way a language model outputs words. The training trick is to start from a vision-language model already pretrained on a huge amount of web text and images, then fine-tune it so that some of its output tokens are read as robot joint and gripper commands instead of text. Because the base model already learned how words relate to images from the web, the robot inherits that knowledge for free. Told to pick up the extinct animal, it reaches for the plastic dinosaur, even though no one taught it that mapping, because the connection between those words and that image was already there. The same holds for instructions like grab the smallest object or hand me something to hammer with, the reasoning comes from the language model underneath. The catch is data and speed. Real robot demonstrations are far scarcer and more expensive than web text, so the action side of the model is thin by comparison, and running a model this large fast enough to control a moving arm is a hard engineering problem in its own right. The robot was never given a rule connecting that sentence to that object. It already knew, and fine-tuning just taught it to answer with a movement. #robotics #vla #ai #foundationmodels #ravenextechnologies
